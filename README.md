# IROH interactive raster layers

19 PNG layers on a 900 × 1086 source canvas. The layers were supplied as the final layered IROH package for subtle 2D animation.

Runtime behavior:
- head/face group: subtle tilt
- iris layers: pointer tracking
- closed-eye layers: blink and password privacy state
- pointing arm: small idle/success rotation
- body: subtle floating motion
- spark/cheek layers: subtle accent motion

Keep transformations small because the source mascot originated from a flattened raster illustration and hidden joints were reconstructed for 2D animation.
