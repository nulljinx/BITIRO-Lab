# BITIRO Lab v7.35 — S03 feedback formativo

## Objetivo
Refinar S03 para que BITIRO informe qué está ocurriendo durante la prueba sin revelar cómo resolver el desafío.

## Cambios
- El panel de feedback muestra progreso observable de S03: obstáculos distintos detectados e intersecciones respondidas.
- El estado inicial explica que la pista ya está preparada con 3 obstáculos y 3 intersecciones.
- Si la LCD aumenta más que la cantidad de obstáculos distintos detectados, BITIRO advierte que un mismo obstáculo podría estar contándose más de una vez.
- La advertencia no menciona `while` ni entrega código; describe solamente el problema observado.
- Al completar los cuatro criterios se muestra `Desafío S03 superado`.

## Criterio pedagógico
BITIRO muestra evidencia y consecuencias del programa, pero la estrategia de solución queda a cargo del estudiante.
