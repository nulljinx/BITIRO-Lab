# BITIRO Lab v7.21 — Calibration polish

## Ajustes realizados
- Se simplificó el modo calibración para que no compita con controles de ejecución.
- Se ocultó la barra inferior del simulador mientras se calibra (`reiniciar`, `velocidad`, `pausar`, `detener`).
- Se retiraron los botones de rotación `-15°` y `+15°` del panel de calibración.
- Se mantuvieron solo las acciones realmente útiles en calibración: `Inicio`, `Limpiar` y `Guardar calibración y volver`.
- Se pulió visualmente el panel pedagógico de calibración con tarjetas, mejor jerarquía y menos aspecto genérico.
- Se rediseñó `Misión y funciones` en el editor para que los objetivos se lean como pasos claros y no como texto corrido.

## Intención pedagógica
La calibración debe enseñar umbral, contraste y diferencias entre sensores. Por eso se eliminan controles que distraen y se refuerza la lectura guiada de objetivos e instrucciones.
