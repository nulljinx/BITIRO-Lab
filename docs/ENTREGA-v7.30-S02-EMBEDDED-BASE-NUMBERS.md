# BITIRO Lab v7.30 — S02 números integrados en las bases

## Cambio visual
- Se eliminaron las etiquetas flotantes `BASE 1`, `BASE 2` y `BASE 3` del modelo 3D.
- Los números `1`, `2` y `3` ahora se dibujan directamente sobre el centro de cada zona final verde.

Que la identificación de las bases parezca parte del plotter físico y no un elemento flotante de interfaz. Esto reduce ruido visual y deja visible la geometría completa de S02.
