# BITIRO Lab v5.3 — Token Guard

- El auditor de design tokens ahora detecta `#hex`, `rgb()`, `rgba()`, `hsl()`, `hsla()`, `hwb()`, `lab()`, `lch()`, `oklab()`, `oklch()` y `color()` fuera de `tokens.css`.
- Se migraron los colores funcionales con alfa (`rgba`) desde CSS de features a tokens centralizados.
- Se eliminaron los restos violeta `rgba(118,88,255,...)` de Explorer/Chrome.
- Explorer, Workspace, Art Direction, Product Polish y Global consumen variables para transparencias, glows, grids y sombras.
- El cobre sigue reservado para acción/señal/movimiento; azul/cian para marca/estructura.
