# BITIRO Lab v7.82 — S01 Student Threshold

Ajustes pedagógicos finales del modo de calibración de S01.

- S01 muestra únicamente el sensor central en la telemetría, porque es el sensor utilizado por el seguidor de línea trabajado en esta sesión.
- BITIRO ya no calcula ni recomienda un umbral.
- Después de medir blanco y negro, el estudiante debe calcular y escribir su propio valor intermedio.
- El sistema valida que el valor ingresado esté entre la mayor lectura blanca y la menor lectura negra.
- La etapa de prueba conserva ajustes finos de ±5 solo después de que el estudiante haya propuesto su primer umbral.
- El flujo sigue siendo: medir blanco → medir negro → calcular umbral → probar → guardar.
