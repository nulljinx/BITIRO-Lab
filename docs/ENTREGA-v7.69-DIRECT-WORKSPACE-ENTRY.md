# BITIRO Lab 7.69 — Direct Workspace Entry

## Cambio principal

`/espacios` deja de funcionar como paso intermedio para cuentas que solo tienen un grupo vinculado.

- 1 grupo: redirección inmediata al espacio institucional.
- 0 grupos: se conserva la pantalla de vinculación por código.
- 2 o más grupos: se conserva el selector porque existe una elección real que hacer.

Esto mantiene el onboarding y los casos multi-grupo sin obligar al usuario normal a pasar por una pantalla innecesaria.
