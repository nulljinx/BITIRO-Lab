# BITIRO Lab v7.50 — IROH Mustakis mascot hero

## Objetivo
Reemplazar la vista previa técnica del simulador en el hero público por la mascota IROH aprobada por el usuario, manteniendo el foco educativo y la identidad de Fundación Mustakis.

## Cambios
- Se incorpora `public/brand/iroh/iroh-mustakis-mascot.webp`.
- El hero deja de mostrar pista + código + LCD en miniatura.
- IROH pasa a ser el protagonista visual del hero.
- Se mantiene el flujo pedagógico Comprende → Programa → Prueba en su sección dedicada.
- Se agregan animaciones sutiles de flotación y destellos.
- `prefers-reduced-motion` desactiva estas animaciones.
- No se modifica el simulador, parser, física ni contenido S01–S03.
